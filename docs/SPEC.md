# 期待する動作

MacBookを閉じても、画面をロックしたままAIエージェントなどの処理を続けられること。

- 「Awake Modeに入る」メニューまたはショートカットで画面ロックとスリープ防止を開始する。ロックできなければスリープ防止を続けない。
- 開始時にバッテリー駆動中で残量が下限以下なら、通常のスリープ状態を確認して画面ロックのみ行う。下限超過または電源接続中はスリープ防止も開始する。ロックのみの後に残量・電源状態が変わっても、自動では開始しない。
- 蓋を閉じたら画面を消灯する。音量やミュート設定は勝手に変えない。
- ロック解除・設定時間の経過・バッテリー駆動中の残量下限到達で、通常のスリープ動作に戻す。蓋を開くだけでは停止しない。
- 時間は「無制限」を選択できる。無制限でもロック解除・バッテリー下限・アプリ終了による停止は維持する。初期値は120分・残量下限30%・開始キー⌃⌘W。
- 設定画面を閉じてもショートカットを受け付ける。ログイン時は設定画面・Dockアイコンを表示せずに自動起動し、利用者がアプリを開いたときに設定画面を表示する。システム設定のバックグラウンド処理はAwake本体の名前・アイコンに関連付ける。
- アプリの起動だけでスリープ防止を始めない。
- スリープ防止の開始と画面ロックの確認に成功したときだけ、標準音Submarineを控えめな音量で1回再生する。メニューとショートカットは同じ動作とし、ロックのみ・失敗・停止では鳴らさない。OSの音量・ミュートは変更せず、音の再生失敗で開始を取り消さない。
- ショートカットの待ち受けは画面表示から独立して起動時に登録する。OSがログイン後にアプリを起動するまでの入力受付は保証しない。
- 設定画面は利用者が明示的に開いたときだけ表示する。バックグラウンドのエラーで画面を開かず、失敗状態の保持と必要な復旧の再試行は続ける。
- アプリの表示は日本語と英語に対応し、macOSの優先言語（アプリ別の指定を含む）に従う。対応言語がない場合は英語を使う。言語によって設定値や電源制御の動作は変えない。
- 解除に失敗した場合は成功扱いにせず、利用者が復旧できるようにする。
- アンインストールではスリープ防止の解除を確認して専用設定を削除し、Finderで本体を表示して終了する。本体のゴミ箱移動は利用者が行う。削除途中で開き直しても自動起動の再登録や開始をしない。
