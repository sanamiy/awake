# 期待する動作

MacBookを閉じても、画面をロックしたままAIエージェントなどの処理を続けられること。

- ショートカットで画面ロックとスリープ防止を開始する。ロックできなければスリープ防止を続けない。
- 蓋を閉じたら画面を消灯する。音量やミュート設定は勝手に変えない。
- ロック解除・設定時間の経過・バッテリー駆動中の残量下限到達で、通常のスリープ動作に戻す。蓋を開くだけでは停止しない。
- 設定画面を閉じてもショートカットを受け付ける。ログイン時は設定画面を開かずに自動起動し、利用者がアプリを開いたときに設定画面を表示する。
- アプリの起動だけでスリープ防止を始めない。
- 解除に失敗した場合は成功扱いにせず、利用者が復旧できるようにする。
- アンインストールではスリープ防止の解除を確認して専用設定を削除し、Finderで本体を表示して終了する。本体のゴミ箱移動は利用者が行う。削除途中で開き直しても自動起動の再登録や開始をしない。

実装方法はコード、利用手順は[README](../README.md)を参照。
