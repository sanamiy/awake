## 読む順序と更新先

エージェントは最初に [AGENT_GUIDE.md](AGENT_GUIDE.md) と [SPEC.md](SPEC.md) を読み、その後は担当する変更に関係する資料を参照してください。実装箇所を探すときは [DEVELOPMENT.mdの対応表](DEVELOPMENT.md#実装の入口) を使います。全資料を毎回読み直す必要はありません。

上の表を詳細説明の置き場所とし、他の資料には必要な概要とリンクを残します。例えば、復旧の判断を変えるときはERRORS、手動での操作手順を変えるときはTROUBLESHOOTINGを更新します。READMEへの掲載基準はAGENT_GUIDEで管理します。

SPECには最低限の期待される動作だけを書きます。実装方法・処理順序・画面の細部はコードを参照し、SPECに再記述しません。仕様と実装が食い違う場合は、最新のユーザー依頼とコード・テストを照合し、依頼された範囲で整合させてください。

各資料のコマンドは、特記がなければリポジトリのルートで実行します。設定値の定義元は [DEVELOPMENT.md](DEVELOPMENT.md#製品設定の変更) にまとめています。
