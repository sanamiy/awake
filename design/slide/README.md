# README用スライド

- `awake.html` / `awake.png`：日本語版の編集元と書き出し画像（1280×720）。`README.ja.md` に掲載。
- `awake.en.html` / `awake.en.png`：英語版の編集元と書き出し画像（1280×720）。標準の `README.md` に掲載。
- `awake.css`：両言語共通のレイアウト。英語の文字サイズだけ言語別に調整。
- `macbook.png`：採用中のMacBook素材（1536×1024）。
- `icons/`：Lucideアイコン。出典・ライセンスは [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

文章や配置を変更したら、両言語をブラウザーで確認し、1280×720のスライド部分だけを対応するPNGに書き出します。採用済みのMacBook画像を共用し、言語対応のための再生成は不要です。アプリのビルドは不要です。

## 画像について

内蔵ImageGenで生成したイメージ画像です。Appleの公式写真や正確な製品図ではありません。キーの発光はショートカットの演出であり、Awakeの機能ではありません。
